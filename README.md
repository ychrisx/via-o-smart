# Viação Smart

Aplicativo Expo com login de demonstração e menu inicial inspirado nas referências visuais.

## Executar

```bash
npm install
npx expo start
```

Abra o QR code no Expo Go (SDK 57) ou use `npm run android`, `npm run ios` ou `npm run web`.
